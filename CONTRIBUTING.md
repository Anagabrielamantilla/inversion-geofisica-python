# Contribuciones

Gracias por ayudar a mejorar estos materiales.

1. Abre un *issue* con una descripción reproducible del problema o de la mejora.
2. Mantén los cambios acotados a una sesión.
3. No publiques datos personales, credenciales ni conjuntos de datos sin permiso de distribución.
4. Si modificas un notebook, reinicia el kernel y verifica que las celdas relevantes se ejecuten en orden.
5. Describe las dependencias y fuentes de datos adicionales en el *pull request*.

Los materiales no incluyen una licencia abierta. Las contribuciones no implican autorización para redistribuir contenidos de terceros.
